🚀 发布 Webull CLI（Go binary）+ 7 项增强 MCP 技能：AI 生态的"全栈"扩展
8 月 4 日，Webull 通过 PR Newswire 发布 AI 交易生态的重大扩展。三个方向同步推进：① Webull CLI——零依赖 Go binary，专为 AI Agent 设计，支持股票/期权/加密的完整下单与查询；② ChatGPT / Claude / Grok 原生连接器——直接在三个聊天机器人中作为应用调用；③ 7 项增强 MCP 技能——包括 Capital Flow Analysis（资金流分析）、Stock Snapshot（股票快照）、Industry Comparison（行业对比）、Forecast EPS（盈利预测）、SEC Filings（财报检索）、Earnings Calendar（日历）、Dividend Calendar（股息日历）。Webull CEO Anthony Denier："Webull 不再只是交易终端，而是 AI 时代的财富管理操作系统。"
PR Newswire 官方新闻稿 (8/4)
08/04
🛠️ Webull CLI 设计哲学：零依赖 + 单一二进制，让 AI Agent 直接调用交易 API
Webull CLI 是本次发布的核心创新——基于 Go 语言构建的单一可执行文件，无 Python/Node 等任何运行时依赖，可在 macOS/Linux/Windows 三端原生运行。专为 AI Agent 工作流设计，支持账户查询、行情拉取、订单提交等完整交易操作。这与 IBKR MCP（模型控制协议）开放、Robinhood Agentic Trading MCP、长桥 Agent Platform 形成"四强格局"——中资与美股券商共同争夺 AI Agent 时代的入口位置。
Webullcorp Newsroom

📊 MCP 技能套件 7 维度扩展：从单一聊天到全投资决策
7 项新技能覆盖投资者最常用的决策环节：① Capital Flow Analysis——资金流入流出追踪；② Stock Snapshot——单只股票的多维度快照；③ Industry Comparison——同行业多公司横向对比；④ Forecast EPS——盈利预测查询；⑤ SEC Filings——10-K/10-Q/8-K 文件检索；⑥ Earnings Calendar——财报发布日历；⑦ Dividend Calendar——股息发放日历。这套技能涵盖了从"原始数据获取"到"投资决策生成"的完整链路。

💡 可借鉴点

Webull CLI = Agent 原生 Webull CLI 是行业首批面向 AI Agent 设计的券商 CLI——零依赖 Go binary 让 Agent 可以不安装任何运行时直接调用。这种"为 Agent 而建"的思路比"为人类优化、向 Agent 兼容"的设计领先一代，类似于 Linux 容器化相对于传统虚拟机
多模型 + 多技能矩阵 Webull 同时支持 ChatGPT / Claude / Grok 三个原生连接器，加上 7 项 MCP 技能——这是目前行业最完整的"AI 模型 + AI 技能"双层矩阵。这种"不绑定单一 AI 模型"的开放策略，与 IBKR 走 MCP 开放标准的逻辑一致
全投资链路覆盖 7 项 MCP 技能覆盖了从"看到"（Capital Flow/Stock Snapshot）→ "理解"（Industry Comparison/Forecast EPS）→ "决策"（Earnings Calendar/Dividend Calendar）→ "验证"（SEC Filings）的全链路。这套框架对内容运营有直接借鉴：内容产品是否也能做到"投资者全链路伴随"
